# Aurelytix

## Turning Campaign Data into Intelligent Decisions.

Aurelytix is an enterprise-grade AI-powered AdTech Analytics Platform designed to analyze advertising campaign performance across multiple channels and provide actionable business intelligence.

## Project Status

🚧 Under active development.

## Technology Stack

- Python
- Flask
- SQLAlchemy
- MySQL
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Bootstrap
- JavaScript
- Chart.js
- ApexCharts
- Leaflet
- GitHub

## Core Capabilities

- Campaign Management
- Advertiser Analytics
- Audience Analytics
- Geographic Analytics
- Channel Performance
- Revenue Analytics
- Campaign Forecasting
- AI Recommendations
- Budget Optimization
- Reporting
- REST APIs

## Architecture

The platform follows a modular enterprise-oriented architecture using:

- Flask Application Factory
- Blueprints
- Service Layer
- Repository Layer
- SQLAlchemy ORM
- REST APIs
- Analytics Services
- Machine Learning Services
- Configuration Management
- Environment Variables
- Automated Testing
